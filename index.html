The API client that stays on your desk

Courier is a free, open-source app for testing APIs: REST, GraphQL, gRPC, WebSocket, Kafka and more. No account, no sign-in, no cloud. Your collections never leave your computer.

Every protocol, one app

Test whatever your services speak

No plugins, no extra tools. Each protocol has its own editor built for it.

HTTP REST

Every method and body type, file uploads, cookies, redirects, proxies and client certificates.

GQL GraphQL

Queries with variables, a schema explorer, and live subscriptions over WebSocket.

gRPC gRPC

All four call types using server reflection or your own .proto files. No code generation.

WS WebSocket

Connect, send text, JSON or binary messages, and watch every frame in a searchable log.

SIO Socket.IO

Namespaces, auth payloads and acknowledgements. Every incoming event is captured.

MQTT MQTT

Publish and subscribe over TCP, TLS or WebSocket, with QoS, retain and last will.

SSE Server-Sent Events

Stream events from any endpoint, including streaming LLM APIs that need a POST body.

SOAP SOAP

Import a WSDL, pick an operation and get a ready-made envelope. WS-Security included.

KAFKA Kafka

Produce and consume messages directly, with SASL and TLS. No Java or extra tools needed.

Organise

Collections, folders and environments

Group requests by project or microservice, nest folders as deep as you like, and switch between Dev, Staging and Production with one click.

  • {{variables}} work everywhere and turn red when undefined
  • Secret values stay masked on screen
  • Set auth once on a folder; every request inside inherits it
Automate

Tests, chained requests and a runner

Check status codes, headers and JSON fields without writing scripts. Capture a value from one response and use it in the next request.

  • Assertions on status, timing, headers, body text and JSON paths
  • Run a whole folder in order, with iterations and a pass/fail summary
  • Code snippets in 9 languages, from cURL to Go
Secure

Every common auth scheme, built in

From a simple API key to the OAuth 2.0 browser flow with PKCE. Courier opens your browser, catches the callback and stores the token.

  • API key, Bearer, Basic, Digest, NTLM
  • OAuth 1.0 and OAuth 2.0 (all grant types)
  • AWS Signature v4, Hawk, Akamai EdgeGrid, JWT
Real time

Live connections you can watch

WebSocket, Socket.IO, MQTT, SSE and Kafka sessions show every message as it arrives, with timestamps, search and export.

  • Send text, JSON, XML or binary messages
  • Filter sent and received messages, copy any one
  • Several connections can stay open in different tabs
Bring your work

Import from Postman and Insomnia

Move over in a minute. Courier reads Postman collections, environments and full data dumps, Insomnia exports, and cURL commands.

  • Folders, auth, bodies and variables come across
  • Export to Courier JSON or Postman Collection v2.1
  • Paste a cURL command and it becomes a request

Install

Get Courier

Version 1.0. Pick your system below.

Windows 10 or 11, 64-bit. No admin rights needed.

Download installer (.exe)

Seeing “Windows protected your PC”? The installer isn’t code-signed yet. Click More info, then Run anyway.

Prefer no installer? Get the portable .zip, extract it anywhere and run courier.exe.

macOS 12 Monterey or newer. One app for both Apple Silicon and Intel Macs.

With Homebrew

brew install --cask ranefattesingh/tap/courier

Or download

Download for macOS (.zip)

Unzip it and drag Courier into your Applications folder.

First launch The app isn’t notarized by Apple yet, so macOS blocks it the first time. Open System Settings → Privacy & Security, scroll down and click Open Anyway. You only do this once.

Ubuntu 22.04 or newer, Debian 12 or newer, Linux Mint, Pop!_OS and other Debian-based systems (64-bit Intel/AMD). Adding the repository keeps Courier updated with apt upgrade.

sudo install -d -m 0755 /etc/apt/keyrings
curl -fsSL https://ranefattesingh.github.io/courier/courier.gpg | sudo gpg --dearmor -o /etc/apt/keyrings/courier.gpg
echo "deb [arch=amd64 signed-by=/etc/apt/keyrings/courier.gpg] https://ranefattesingh.github.io/courier/apt stable main" | sudo tee /etc/apt/sources.list.d/courier.list
sudo apt update && sudo apt install courier-api

Then open Courier from your app menu, or run courier-api in a terminal. Prefer a single file? Download the .deb.

Fedora 36 or newer, RHEL, Rocky and AlmaLinux 9 (64-bit Intel/AMD). Updates arrive with dnf upgrade.

sudo curl -fsSL -o /etc/yum.repos.d/courier.repo https://ranefattesingh.github.io/courier/rpm/courier.repo
sudo dnf install courier-api

The first time, dnf asks you to trust the Courier signing key: answer y. Prefer a single file? Download the .rpm.

For other 64-bit Linux distributions, use the portable archive. It needs GTK 3 installed.

mkdir -p ~/.local/opt/courier
curl -fsSL https://github.com/ranefattesingh/courier/releases/latest/download/courier-linux-x64.tar.gz | tar -xz -C ~/.local/opt/courier
~/.local/opt/courier/courier
